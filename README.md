# Maxwell Modes, Nodal Density, and Nonlinear Frozen Spectra

A short computational project exploring two related questions in cylindrical electromagnetic cavities:

1. **How does oscillatory/nodal structure become more complicated as the linear spectral index increases?**
2. **How do instantaneous eigenvalues and eigenfunctions change when the background field evolves under a nonlinear Maxwell-type dynamics?**

The repository contains two Colab-ready experiments and a short report (less than five pages) explaining the mathematics and interpretation.

## 1. Linear time-harmonic Maxwell eigenproblem

For a perfectly conducting cavity, the magnetic-field formulation can be written schematically as

\[
\nabla\times\nabla\times H = \lambda H,
\qquad \nabla\cdot H=0,
\]

with PEC-compatible magnetic boundary conditions

\[
n\cdot H=0,
\qquad
n\times(\nabla\times H)=0
\quad\text{on }\partial\Omega.
\]

The eigenvalue is related to the angular frequency by \(\lambda=\omega^2\) after nondimensionalization. In product and cylindrical geometries, Maxwell modes can be organized using scalar transverse eigenproblems and polarization families.

### Scalar nodal experiment used here

The first numerical experiment deliberately uses the simpler scalar cylindrical Dirichlet family

\[
\phi_{m,\ell,p}(r,\theta,z)
=
J_m\!\left(\alpha_{m,\ell}\frac rR\right)
\cos(m\theta)
\sin\!\left(\frac{p\pi z}{H}\right),
\]

with

\[
\lambda_{m,\ell,p}
=
\left(\frac{\alpha_{m,\ell}}{R}\right)^2
+
\left(\frac{p\pi}{H}\right)^2.
\]

These scalar modes are **not claimed to be the full vector Maxwell eigenfunctions**. They are a transparent cylindrical proxy for the separated scalar factors that appear in TE/TM descriptions of product-domain Maxwell modes. This keeps the nodal geometry easy to visualize.

For a scalar mode, the nodal set is

\[
\mathcal Z(\phi_j)=\{x:\phi_j(x)=0\}.
\]

Numerically it is approximated by

\[
|\phi_j(x)|\le \varepsilon\|\phi_j\|_{L^\infty},
\]

with a small relative threshold \(\varepsilon\). The cumulative nodal-density proxy is

\[
D_J(x)
=
\frac1J\sum_{j=1}^{J}
\mathbf 1_{\{|\phi_j(x)|\le \varepsilon\|\phi_j\|_\infty\}}.
\]

The videos show where nodal surfaces repeatedly pass as more modes are included. Higher spectral index usually brings finer oscillation and more intricate geometry, but **nodal complexity is not required to increase monotonically from one eigenfunction to the next**. Courant's theorem concerns the number of scalar nodal domains and gives an upper bound, not monotone growth. For vector Maxwell fields, the zero set is a different object and the scalar Courant theorem does not directly apply.

## 2. Nonlinear Maxwell-type time evolution

The second experiment studies the reduced conservative model

\[
u_{tt}+Au+\gamma P(|u|^2u)=0,
\qquad
A=\nabla\times\nabla\times,
\]

where \(P\) denotes projection onto the reduced divergence-free space. The cubic term is a Kerr-type self-interaction: the effective response depends on field amplitude, so scaling the field changes the equation.

A Galerkin approximation

\[
u(t,x)=\sum_{j=1}^{M}q_j(t)\phi_j(x)
\]

produces a finite-dimensional nonlinear oscillator system

\[
q''+\Lambda q+\gamma G(q)=0.
\]

At each physical time \(t\), the code freezes the evolving background \(u(t)\) and linearizes:

\[
L(t)v
=
Av
+
\gamma P\bigl(|u(t)|^2v+2(u(t)\cdot v)u(t)\bigr).
\]

It then solves

\[
L(t)\phi_j(t)=\lambda_j(t)\phi_j(t).
\]

The curves \(\lambda_j(t)\) are therefore **instantaneous or frozen-background eigenvalues**. They are not the fixed spectrum of one time-independent operator. When \(\lambda_j(t)>0\), \(\sqrt{\lambda_j(t)}\) gives an instantaneous frequency scale for small perturbations around the current background.

The 3D visualization uses mixed toroidal and poloidal cylindrical basis functions so the smallest positive frozen eigenfunction can have a nonzero axial component and genuinely three-dimensional field lines.

## 6. Scope and limitations

This is a numerical demonstrator, not a full Maxwell eigensolver. The linear nodal-density calculation uses scalar cylindrical Dirichlet modes as an interpretable proxy for separated mode factors. The nonlinear problem is a reduced Galerkin Maxwell-type model with a cubic interaction. The frozen spectrum is useful for visualizing how an evolving nonlinear background changes local spectral structure, but it should not be identified with a rigorous spectral flow of the full nonlinear Maxwell PDE without further analysis.
